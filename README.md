# 改值工具（免 root・虛擬空間版）

以開源虛擬化引擎 [NewBlackbox](https://github.com/LamPPKK/NewBlackbox)（Apache-2.0）為底，
把遊戲裝進 App 內的虛擬空間執行；遊戲與搜改工具在同一個進程，因此免 root 也能搜尋、修改遊戲數值。

## 用法
1. 開啟 App，點右下「+」，從手機已安裝的 App 或 APK 檔把遊戲加入虛擬空間。
2. 在虛擬空間內啟動遊戲，畫面上會出現可拖曳的「改」按鈕。
3. 點開面板：選類型 → 輸入數值 → 新搜尋 → 在遊戲內改變數值 → 再搜 → 改值／鎖定。
4. 面板底部的「引擎自檢」可確認該進程是否允許讀寫自身記憶體。

## 搜改功能
整數 4B/8B、浮點、雙精度；精確／範圍／未知初始值；=值、範圍、變大、變小、有變、不變；改值、鎖定、全改、全鎖。

## 取得 APK
推上 main 後 GitHub Actions 自動建置，APK 在 Releases（固定簽章，可直接覆蓋安裝）。
